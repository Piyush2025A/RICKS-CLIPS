# EXP-a07-20261128-01: region-wise native sharpness / colour grid across RC30

- **Hypothesis:** background defocus and haze can be measured from a 4x3 grid of native-resolution cells (rows: 0-20 %, 20-40 %, 40-58 %, 82-100 % of height; caption band 58-82 % excluded).
- **Single variable:** grid row (screen height) -> sharpness (Laplacian var, normalised by luma variance), saturation, L*, chroma.
- **Held constant:** decoder (OpenCV), native 1080x1920, sampling every 10th frame (videos 1-4) / every 30th (5-30; CPU shared).
- **Spec:** analysis only, no render. Outputs private (`~/ricks-clips-private/analysis-data/rc30/agents/a07-depth-perspective-specialist/regions_*.csv`).
- **Success criteria:** calibration of the normalised-sharpness (hf) to Gaussian sigma gives a monotonic curve usable for sigma 0-3 px.
- **Commands:** `.venv-analysis/bin/python regions.py <n> [step]`; `calib.py`; scripts copied to `data/`.
- **Cost:** CPU only.
