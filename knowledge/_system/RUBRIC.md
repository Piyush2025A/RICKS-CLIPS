# Evaluation rubric (structure only)

Used by A28 (creative evaluation) and A29 (release QA). Scores are **judgements** that must cite evidence; they are
never reported as measurements. Target values are filled in only from approved findings (`TECHNIQUES.md`), never
invented here.

| Area | Owner of fixes | Evidence A28 must cite |
|---|---|---|
| Character identity and consistency | A01 | frames of every appearance |
| Proportion and anatomy | A03 | A03 conformance check |
| Expression readability and timing | A02 | strips around swaps, word timings |
| Body motion | A04 | every-frame strips of the action |
| World design and scale | A05 | establishing frames |
| Layering / parallax | A06, A07 | strips across moves |
| Depth (DOF, haze, perspective) | A07 | crops subject vs background |
| Textures and props | A08 | zoomed crops |
| Lighting and integration | A09 | lit/shade crops, character faces |
| Shading and outlines | A10 | edge zooms |
| Colour and grade | A11 | colour stats vs approved ranges |
| Effects | A12 | effect strips |
| Camera | A13 | motion stats + strips |
| Composition | A14 | safe-zone overlays |
| Transitions | A15 | strips −6..+6 frames |
| Pacing | A16 | EDL + event density |
| Story, hook, script | A17–A19 | script, claim ledger |
| Voice, SFX, music, mix | A20–A22 | loudness + sync reports |

Scale: 0–10 per area with a one-line reason and ≥ 1 evidence reference; `n/a` allowed with reason.
Release QA (A29) is pass/fail per checklist item, not a score.
