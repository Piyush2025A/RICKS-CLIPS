# Orchestration protocol (master director ↔ 29 specialists)

The master director is the main Claude Code session. Specialists are ordinary Claude Code subagents defined in
`.claude/agents/` (no experimental agent teams). Specialists have no `Agent` tool, so they cannot spawn agents.

## 1. Concurrency and cost
- **At most 2 specialists run at once** (user rule). Default is 1; use 2 only for independent tasks with disjoint
  file ownership.
- Prefer `sonnet` specialists; `opus` is reserved for A18 (script), A28 (independent evaluation), A29 (release QA).
- Every brief sets a scope small enough to finish within the agent's `maxTurns`.

## 2. Work cycle
1. **Plan** — director picks the next task from `PROGRESS.md`, checks `OWNERSHIP.md`, and checks the knowledge base
   for existing findings (avoid redundant research).
2. **Brief** — director writes a brief (`templates/brief.md`) of ≤ 300 words: goal, phase, inputs by path, outputs by
   path, evidence to reuse, budget/approval, stop condition. Context is passed **by file path, never by pasting
   large content**.
3. **Run** — one (or two) subagent(s) invoked by name.
4. **Hand-off** — agent returns ≤ 250 words (`templates/handoff.md`) with paths; detail lives in its files.
5. **Review** — director checks the diff stays inside the agent's ownership, labels are present, no media or
   secrets were added.
6. **Checkpoint** — director updates `PROGRESS.md` (task status + evidence paths) and commits/pushes at every
   completed milestone, so an interrupted session can resume from `PROGRESS.md` alone.

## 3. Shared dataset and measurements (no redundant research)
- One frozen dataset: `knowledge/dataset/MANIFEST.json` (RC30). No agent adds, drops or substitutes videos.
- A27 runs first in Phase 3: frame index, frame accounting, shared per-frame tables (colour stats, frame
  difference, global motion, boundary candidates, audio envelope). All other analysts consume these.
- A new measurement that more than one agent needs is requested from A27 and added to the shared tables.
- Contact sheets / frame strips are generated by A27 scripts into private storage; any agent that views them logs
  it in its own visual coverage ledger.

## 4. Phase 3 analysis order (proposed; max 2 concurrent)
1. A27 (frame index + shared tables) — alone.
2. A20 (transcripts + word timings) ∥ A15 (transition classification).
3. A13 (camera) ∥ A16 (pacing).
4. A14 (composition) ∥ A07 (depth).
5. A09 (lighting) ∥ A11 (grade).
6. A10 (outlines) ∥ A08 (textures).
7. A01 (identity) ∥ A03 (proportions); then A02 (expressions) ∥ A04 (motion).
8. A05 (world) ∥ A06 (layering); A12 (VFX) ∥ A21 (SFX); A22 (music/mix) ∥ A19 (hooks); A17 (topics) ∥ A18 (structure).
9. A28 reviews a sample of findings for evidence quality (it does not grade its own work).
Engineering agents (A23–A26) are not used for reference analysis.

## 5. File ownership and conflicts
- Exclusive write ownership per `OWNERSHIP.md`, validated by `tools/validate_agents.py`.
- Two concurrent agents must have disjoint owned paths for the task; the director checks before launching.
- Cross-agent interfaces are written as contracts in `knowledge/contracts/<name>.md` (`templates/contract.md`);
  changes need sign-off from every party listed.
- If an agent needs a change in another agent's file, it writes a request in its hand-off; the director routes it.

## 6. Independence of evaluation
- A28 never evaluates an artefact it authored and receives no producer self-scores before scoring.
- A29 does not sign off changes to its own QA scripts; the director or A28 reviews them.
- Producers may not mark their own techniques as approved; approval = passed experiment + A28 review + director
  decision log entry.

## 7. Resuming interrupted work
- `PROGRESS.md` lists in-flight tasks with agent, brief path and expected outputs.
- On resume: read `PROGRESS.md`, check which expected outputs exist in git, re-brief only the missing part.
- Long tasks are split so each sub-task produces committed output.

## 8. Escalation to the user
Stop and ask the user when: spending credits/money, any authentication, any download of reference footage or tools,
a phase boundary, a licence/ToS question, or a contradiction that changes an approved decision.

## 9. Known platform behaviour (from official docs, 2026-11-27)
- Subagent files are Markdown + YAML frontmatter in `.claude/agents/`; edits are detected within seconds without
  restart (docs), but a session may need restarting if an agent is not found.
- Unknown frontmatter fields are silently ignored; `tools` takes whole-tool names (no per-command Bash patterns), so
  Bash restrictions are enforced by instructions and, if desired later, by `permissions.deny` rules in settings.
