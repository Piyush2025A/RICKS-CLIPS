# Implementation contracts

Director-owned interface agreements between specialists (format: `../_system/templates/contract.md`). A contract is
created when two agents first exchange a file, value table or code interface, e.g. `dof-table` (A07 → A10/A25),
`light-presets` (A09 → A10/A11), `word-timings` (A20 → A02/A13/A16/A21/A22), `rig-parts` (A02/A03 → A04/A24),
`asset-manifest` (A23 → A24). No contract exists yet.
